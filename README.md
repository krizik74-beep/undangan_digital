# Undangan Monorepo

Monorepo gabungan:
- `frontend/` — dari repo `undangan_animation` (React + Vite)
- `backend/` — dari repo `undangan_php_backend` (CodeIgniter 4)

## Struktur

undangan-monorepo/
  frontend/
  backend/

## Dev

- Frontend: `cd frontend; npm install; npm run dev`
- Backend: `cd backend; composer install; php spark serve`
